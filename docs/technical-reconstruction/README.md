## Why it is kept, and why it is out of date

It was written **before the universal patcher existed**, to record what had been
proven so that patcher could be built from it. Its own stated purpose is "a
reconstruction record and an implementation specification for the future
universal patcher" — the thing this repository now ships.

So it is a record of how the work was scoped, in the same spirit as
[`../phase-0-plan.md`](../phase-0-plan.md). It is **not** a description of what
KMRP does today.

## Two things to know before regenerating it

**The generator writes to the wrong place.** `OUT` in
`tools/build_technical_reconstruction_doc.py` points at
`docs/KOTOR_UI_Gold_Build_Technical_Reconstruction.docx` — one directory above
these files. Running it as-is drops a new file beside `docs/` rather than
updating this folder, and leaves what is here untouched.

**It cannot currently be run.** It imports `python-docx`, which is **not
installed** on the build machine; `requirements.txt` records that. CI does not
catch it, because CI byte-compiles `tools/` without importing anything.

Both would have to be fixed before this document could be brought up to date, and
neither has been. Stated here rather than left to be discovered.
