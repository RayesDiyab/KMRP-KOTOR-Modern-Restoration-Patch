## Measured font evidence

Read with Pillow/NumPy from `assets/hd-fonts/*.tga`, not inferred from the font
builder: all 18 atlases have 256 distinct alpha values. Intermediate-alpha
pixel counts range from 9,283 (`fnt_console`) to 51,967 (`dialogfont32x32`).
`dialogfont10x10` has 14,517; `fnt_d16x16b` has 27,279. This rules out purely
monochrome source rasterization. It does not determine screen-space filtering,
per-resolution edge quality, or the cause of the user's reported aliasing.

The clean input is 4,042,752 bytes, SHA-256
`761F9466F456A83909036BAEBB5C43167D722387BE66E54617BA20A8C49E9886`.
No new on-disk game-byte edits were made. The inventory reports 68 code/data
runs and zero undocumented runs. Removed hook addresses are **VA** addresses
in the original image (`FILE = VA - 0x400000`); appended PE sections use their
section mappings instead.

Runtime blocker: the initial native test executable compiled, but Windows
Restart Manager reported Bitdefender Virus Shield (`VSSERV`) holding it open.
It was subsequently removed. Security settings were not changed. The user was
asked to inspect Bitdefender before the test is retried.
